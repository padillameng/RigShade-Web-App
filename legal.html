Terms of use

RigShade Control is a free, unofficial tool for editing the three presets of a Cube Baby multi-effects pedal from a desktop browser. It is provided as it is, without warranty of any kind. It writes to the pedal flash; the page checks what it writes by reading it back, but the risk of using it stays with you, and a preset you care about should be exported first.

RigShade is an independent project. It is not affiliated with, endorsed by or sponsored by M-VAVE or CUVAVE. The pedal's name is used only to say what this page talks to.

Privacy

This page runs in your browser. It has no account, no analytics, no cookie and no server of its own: every byte it needs is the page itself. The browser refuses any outbound request from it, so the only network traffic is the download of the page.

Your presets and the bank you build stay on your computer, in this browser's localStorage, and nowhere else. Clearing site data deletes them.

The page asks the browser for permission to use Web MIDI, which is what reaches the pedal over USB. That permission is the browser's, not ours. The only device the page talks to is the one you pick in the Link panel.

The tester list, when it opens, is a separate page that does collect an address, and it says so there.
